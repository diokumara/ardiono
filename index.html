Pilih Sistem Operasi Kamu

Arduino IDE mendukung berbagai sistem operasi. Klik sesuai OS kalian untuk langsung menuju opsi yang sesuai.

Windows

Windows 10 / 11 (64-bit). File installer resmi format .exe atau versi ZIP Portable.

  • Windows Win10/Win11 Installer
  • MSI / Zip file support
Download untuk Windows

macOS

Mendukung macOS 10.14 (Mojave) ke atas. Kompatibel dengan Apple Silicon & Intel.

  • Intel Processor (64-bit)
  • Apple Silicon (M1/M2/M3)
Download untuk macOS

Linux

Tersedia format AppImage 64-bit yang praktis tanpa perlu kompilasi ulang.

  • Linux AppImage 64-bit
  • Linux ZIP Archive

Panduan Lengkap

Langkah Demi Langkah Install Arduino IDE

Ikuti petunjuk sederhana ini untuk memasang software di perangkat komputer kalian.

1

Unduh File Installer

Klik tombol download di atas untuk mengunduh berkas resmi dari situs Arduino.cc sesuai OS kalian.

2

Jalankan Installer

Buka berkas `.exe` atau `.dmg` yang telah diunduh. Jika muncul izin keamanan (UAC), pilih "Yes / Allow".

3

Persetujuan & Driver

Klik "I Agree" lalu centang opsi untuk menginstall Driver USB (Sangat penting agar board terdeteksi).

4

Selesai & Siap Pakai

Tunggu proses instalasi hingga selesai. Buka Arduino IDE melalui Shortcut Desktop yang telah dibuat.
